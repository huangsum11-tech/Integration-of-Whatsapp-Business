# Baton 接棒：品牌指引

## 名稱

**Baton 接棒**

接力賽中，跑手之間傳遞的是一枝棒，比賽一直延續。這個 app 做的就是同一件事：

- **對話交接**：同事之間把客戶對話交給對方，連同交接備註，客戶不用重複說明。
- **業務延續**：同事離職，「棒」交給下一位，對話、聯絡人與成交紀錄全部留在公司。
- **號碼不變**：棒還是同一枝，客戶照舊 WhatsApp 你現有的號碼。

**標語：** 對話接棒，生意不斷。

**後備名稱（如商標或域名已被使用）：**

| 同線 Sameline | 全團隊同一條線回覆客戶 |

## 標誌

兩段圓角弧線（薄荷綠與珊瑚紅）首尾相接成一枝棒，代表兩位同事交接中的同一個對話。檔案：`web/public/favicon.svg`，React 版本在 `web/src/components.tsx` 的 `Logo`。

## 配色

刻意**不用** WhatsApp 的亮綠色。這是公司的工具，不是 WhatsApp 的山寨版。深墨綠帶出可靠、專業的感覺，暖米色背景長時間看對話也不刺眼。

| 名稱 | Hex | 用途 |
| --- | --- | --- |
| Ink 墨 | `#12201C` | 側邊欄、登入頁、深色背景 |
| Pine 松綠 | `#0E7C66` | 主要按鈕、同事發出的訊息、正面指標 |
| Pine 50 | `#E6F3EE` | 選中狀態、提示框 |
| Mint 薄荷 | `#3CC9A0` | 標誌、深色背景上的重點 |
| Coral 珊瑚 | `#D9573C` | 未讀數、未分配、交接、需要注意的地方 |
| Iris 鳶尾紫 | `#6C5CE7` | **只用於 AI**：AI 草擬按鈕、AI 草擬的訊息標籤 |
| Amber 50 | `#FFF4D6` | 內部備註（客戶看不到） |
| Paper 紙 | `#F6F4EF` | App 背景 |
| Line | `#E5E1D8` | 分隔線、邊框 |
| Text | `#1B2421` | 正文 |
| Muted | `#66706B` | 次要文字 |

**顏色規則：**

- 紫色只代表 AI。同事一眼就分得出哪些內容是 AI 寫的。
- 黃色只代表內部備註，避免同事誤以為備註已發給客戶。
- 珊瑚紅只用於需要行動的地方（未讀、未分配、交接），不作裝飾。
- 圖表配色（`#008F70` 發出 / `#D9573C` 收到）已經過色弱分辨度測試。

## 字體

- **Noto Sans HK**：正文、中文介面（繁體中文香港字形）

兩款都經 Google Fonts 載入，未能載入時依次改用 PingFang HK、Microsoft JhengHei。

## 介面原則

1. **三欄收件匣**：對話列表、對話內容、客戶資料。所有號碼的訊息集中一處，每個對話都標明經哪個號碼、由哪位同事負責。
2. **AI 是助手，不是自動回覆**：AI 只會草擬，一定由同事檢查後才發送。發出的訊息會標示「AI 草擬」，方便管理層追蹤。
3. **交接看得見**：分配、交接、備註、成交都顯示在對話時間線，接手的同事一看就明白來龍去脈。
4. **廣東話優先**：介面用香港繁體中文，語氣口語、簡短。
5. **手機可用**：860px 以下變成單欄，底部導航。
